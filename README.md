# Revestik

Revestik is a financial and inventory management application designed to help a small business organize its daily operations.

This repository documents the evolution of the project from a client-side JavaScript beta into a full-stack application built with the Microsoft .NET ecosystem.

## Current Version

The current version is the original client-side beta built with HTML, CSS, and JavaScript.

Application data is currently stored in the browser using local storage. This implementation serves as the functional and visual foundation for the upcoming .NET migration.

## Current Features

- Business dashboard
- Quotation creation
- Quotation PDF generation
- Product inventory management
- Purchase registration
- Automatic inventory updates from purchases
- Basic sales and payment tracking
- Responsive interface

## Current Technologies

- HTML5
- CSS3
- JavaScript
- Local Storage
- jsPDF
- jsPDF AutoTable

## Migration Roadmap

Revestik will be migrated incrementally to the following technologies:

- C#
- Blazor
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- Dependency Injection
- Asynchronous programming
- RESTful API integration

The migration will replace browser-based persistence with a relational database and separate the user interface, business logic, and data access responsibilities.
